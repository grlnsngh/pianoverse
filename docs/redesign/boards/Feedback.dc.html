Rules
Chrome stays real. Tab bar, search pill and buttons never become skeletons.
Wait 200 ms before showing any loader. If data arrives sooner, show nothing.
Shimmer: 1.5 s linear loop, #EFEDE8 to #F8F7F4. Content fades in over 150 ms.
Reduced motion: shimmer, keys and spinners stop. Loaders stay visible as static shapes.
