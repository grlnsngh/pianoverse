# Security

Pianoverse is a small app for a piano rental business, built and kept up by one person. If you find a problem in it, please tell me privately first, so it can be fixed before it is written about.

## Reporting a problem

- On GitHub: **Security**, then **Report a vulnerability**, on this repository. That is private between you and me.
- Or by email: pianoverse.app.dev@gmail.com

Please say what you found, where, and how to see it. I will answer as soon as I can, and tell you when it is fixed.

## Please don't

- Open a public issue or pull request that describes the problem before it is fixed.
- Look at, change or delete other people's data, or try the app's accounts with passwords that aren't yours.
- Test by sending the app or its servers a lot of traffic.

## What is here

The app (Expo and React Native), the website pages that GitHub Pages serves, and a small Appwrite Function that deletes an account. The app's data lives in Appwrite; no secret keys are kept in this repository.
